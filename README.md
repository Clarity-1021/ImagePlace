# 物品归位

把透明背景的散件，对照参考图放回底图原来的位置。分离、匹配和叠放都在浏览器里完成，图片不会上传。

上传三张图：

- **参考图**：物品还在正确位置的完整场景。
- **底图**：同一场景，这些物品已经被拿走。
- **物品图**：透明背景的 PNG 或 WebP，物品彼此分开。没有透明通道时不会假装能分开。

放好之后可以在「底图叠放」和「参考图」之间切换，核对是否对齐。物品栏里可以单独隐藏某一件；隐藏只影响叠放结果。匹配不准时，在底图上拖动物品可微调位置，拖右下角可改大小。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器监听 `http://127.0.0.1:43123`。

示例图片在 `public/fixtures/`。页面上的「载入示例」会直接使用它们。重新生成并检查定位：

```bash
npm run verify
```

## 限制

- 不处理旋转，缩放只在 0.5、0.75、1、1.25、1.5 里选择。
- 物品必须分开，重叠的会并成一件。
- 和参考图差别很大、或场景里有重复纹理时，自动位置可能偏，需要手动拖正。
- 长边超过 1600 像素的图会先缩小再处理。
